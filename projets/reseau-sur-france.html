Le projet

Trois mois de stage pour livrer le site vitrine de l'entreprise dans sa charte graphique. Les demandes ont évolué jusqu'au dernier moment, et le site a été livré à temps.

Maquettes dans Figma, visuels dans Photoshop, intégration dans WordPress, mise en ligne chez OVH. J'ai travaillé chaque semaine avec l'équipe marketing pour ajuster les pages.
