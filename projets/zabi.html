ZABI

Un jeu de duel entre super-héros, façon arcade.

Contexte
INSA Hauts-de-France
Période
Avril 2025
Équipe
Équipe de 4
Mon rôle
Développement full stack
Stack
  • Node.js
  • Express 5
  • MongoDB
  • API REST
  • JavaScript

Deux joueurs, deux héros tirés au sort parmi 731, et un combat au tour par tour. Le titre complet du projet : « Les super-héros qui se battent dans le jeu qu'on a développé ».

Voir le code

Les règles

Chaque héros a ses statistiques : intelligence, force, vitesse, résistance, puissance, combat. Chaque type d'attaque peut exploiter une faiblesse de l'adversaire pour un coup critique (plus 20 dégâts), ou au contraire buter sur sa défense (moins 20).

La technique

Une API REST en Express 5 sur MongoDB, alimentée par l'import des 731 héros. L'interface reprend les codes de l'arcade : barres de vie, animations de dégâts et de soin, police pixel.
