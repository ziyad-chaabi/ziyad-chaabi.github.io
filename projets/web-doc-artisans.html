Le projet

Une ébéniste, une potière, un plumassier, un lapidaire. Nous sommes allés les interviewer pour comprendre des métiers qui disparaissent, puis nous avons construit un web-documentaire autour de leurs récits.

Ma part

J'ai mené des entretiens et conçu l'interface dans Figma. Les vidéos ont été montées dans Premiere Pro, puis intégrées dans un site simple, page par métier.
